# FixFlow — ระบบแจ้งปัญหา IT Support

FixFlow เป็นหน้าเว็บตัวอย่างสำหรับช่วยให้ผู้ใช้แจ้งปัญหาและขอความช่วยเหลือจากทีม IT Support ได้ในที่เดียว ออกแบบให้ใช้งานง่าย รองรับหน้าจอคอมพิวเตอร์และโทรศัพท์มือถือ และนำเสนอขั้นตอนการรับเรื่องจนถึงการแก้ไขอย่างชัดเจน

## ความสามารถ

- แสดงบริการช่วยเหลือด้านคอมพิวเตอร์ อุปกรณ์ เครือข่าย โปรแกรม และบัญชีผู้ใช้
- อธิบายขั้นตอนการแจ้งปัญหาและการติดตามงาน
- มีแบบฟอร์มตัวอย่างสำหรับกรอกชื่อ อีเมล ประเภทปัญหา และรายละเอียด
- ตรวจสอบช่องข้อมูลที่จำเป็นด้วยการตรวจสอบมาตรฐานของเบราว์เซอร์
- ปรับรูปแบบหน้าเว็บให้เหมาะกับหน้าจอขนาดต่าง ๆ

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง ไม่จำเป็นต้องติดตั้งแพ็กเกจหรือเปิดเซิร์ฟเวอร์

## ข้อจำกัดของตัวอย่าง

แบบฟอร์มยังไม่ได้เชื่อมต่อกับระบบหลังบ้าน เมื่อส่งแบบฟอร์มจะแสดงข้อความยืนยันตัวอย่างเท่านั้น โดยไม่มีการจัดเก็บหรือส่งข้อมูลจริง
